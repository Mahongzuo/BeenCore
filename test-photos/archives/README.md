# 测试档案：外婆 & 馒头

用来测试「亲友与宠物档案」的 8 张照片。画面来自 Unsplash（经 Picsum 获取），按 [Unsplash License](https://unsplash.com/license) 可免费使用。
照片里的人和故事都是虚构的测试数据；拍摄时间和 GPS 是**人为写进 EXIF 的**。

## 外婆（人，1931 – 2019）

- 头像：`832.jpg`（翻拍的老照片，没有拍摄信息）
- 关系：外婆
- 关于 TA：苏州人，教了一辈子小学音乐。说话很慢，做事很快。家里那架旧钢琴，是她用三年工资换来的。

在档案里点「从相册补记」，选下面 5 张，应该分成 **5 个时刻**：

| 照片 | 写入的时间 | 写入的地点 | 测试配文 |
| --- | --- | --- | --- |
| 1066.jpg | 1995-03-12 10:20 | 上海 | 我出生那天，外婆一直握着我的手，说这孩子手指长，以后能弹琴。 |
| 428.jpg | 2003-07-20 16:05 | 苏州 | 外婆在苏州老房子门口坐了一下午，等我放学。 |

| 768.jpg | 2018-08-09 17:42 | 青岛 | 外婆最后一个夏天。在青岛的海边坐了很久，什么也没说。 |

再点「写下关于外婆的事」直接写一枚：「外婆从苏州的师范学校毕业，那年她二十五岁。」时间选 1956、月份「记不清」。

## 馒头（宠物，狗，2010 – 2024）

- 头像：`1062.jpg`
- 种类：狗；关系：我们家的巴哥
- 关于它：怕冷，冬天一定要裹着毯子才肯睡。打呼噜比我爸还响。
- 补记 `1025.jpg`（2016-10-05 09:12，杭州）：第一次去西湖，馒头裹着毯子不肯下地，被人围着拍了二十分钟。

## 要检查的

- 「传记 → 我的」「印记」「地图」都只有你自己的印记，档案里的不会混进来。
- 档案页有自己的传记和地图，邮戳是墨色的。
- 地图「图层」里打开「亲友与宠物」，档案的印记以墨色出现。
- 删除档案时，它的印记一起删除。

## 公开纪念（第 7 步）

需要后端：`npm run api`（第一次先 `npm run db:migrate:local -w @been/api`），App 里「我 → 以开发者身份登录」。

1. 外婆的档案 → 「公开纪念」→ 地图位置选「苏州」→ 勾选 2003、2009、2018 三枚（「我出生那天」写到了在世的人，故意不勾）→「公开」。
2. 「查看纪念页」：App 里的只读页。「分享链接」打开的是不用装 App 的网页。
3. 换一个浏览器（或无痕窗口）再用开发者身份登录，传送到苏州：地图上有一枚墨色单圈，点开就是纪念页，右上角「⋯」里只有「在网页中打开」和「举报」。
4. 回到外婆的档案 →「公开纪念」→「停止公开」，链接随即失效。
